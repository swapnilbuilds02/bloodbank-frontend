# Screen-to-Table & Endpoint Mapping

| Screen / Hash Route | Primary Endpoints | Database Tables Involved | Primary Operations |
| :--- | :--- | :--- | :--- |
| **Dashboard** (`#/dashboard`) | `GET /api/dashboard/summary`<br>`GET /api/dashboard/blood-groups`<br>`GET /api/dashboard/donation-statistics`<br>`GET /api/requests/summary`<br>`GET /api/dashboard/expiry-alerts`<br>`GET /api/dashboard/recent-donations`<br>`GET /api/dashboard/recent-requests`<br>`GET /api/inventory/expired` | `donor`, `donation`, `bloodinventory`, `bloodrequest`, `bloodissue`, `bloodtest` | Read-only aggregate metrics, charts, and real-time triage. |
| **Donors** (`#/donors`, `#/donors/:id`) | `GET /api/donors`<br>`POST /api/donors`<br>`PUT /api/donors/:id`<br>`DELETE /api/donors/:id`<br>`GET /api/donors/:id/donations` | `donor`, `donation` | Full CRUD on donors, calculates advisory eligibility, displays historical donation records. |
| **Donations** (`#/donations`) | `GET /api/donations/history`<br>`POST /api/donations`<br>`PUT /api/donations/:id`<br>`DELETE /api/donations/:id` | `donation`, `donor`, `bloodbank`, `staff` | Registers collection intake; updates donor last donation date; prompts testing handover. |
| **Blood Tests** (`#/bloodtests`) | `GET /api/bloodtests`<br>`GET /api/bloodtests/safe`<br>`GET /api/bloodtests/unsafe`<br>`POST /api/bloodtests`<br>`PUT /api/bloodtests/:id`<br>`DELETE /api/bloodtests/:id` | `bloodtest`, `donation`, `donor` | Laboratory test results recording; enforces safety rules (Safe only if HIV/Hep/Malaria all Negative). |
| **Inventory** (`#/inventory`) | `GET /api/inventory`<br>`GET /api/inventory/summary`<br>`GET /api/inventory/expiring`<br>`GET /api/inventory/expired`<br>`POST /api/inventory`<br>`PUT /api/inventory/:id`<br>`DELETE /api/inventory/:id` | `bloodinventory`, `donation`, `bloodbank`, `bloodtest`, `bloodissue` | Stock intake; expiry monitoring; shows component shelf lives; inspects associated issues. |
| **Blood Requests** (`#/requests`, `#/requests/:id`) | `GET /api/requests`<br>`GET /api/requests/pending`<br>`GET /api/requests/summary`<br>`POST /api/requests`<br>`PUT /api/requests/:id`<br>`DELETE /api/requests/:id` | `bloodrequest`, `patient`, `hospital`, `bloodissue` | Hospital requests queue; urgency sorting; approval/rejection workflow; fulfillment progress. |
| **Issue Blood Wizard** (`#/issue`) | `GET /api/requests`<br>`GET /api/inventory`<br>`POST /api/issues` | `bloodissue`, `bloodrequest`, `bloodinventory`, `staff` | 3-step wizard with FEFO sorting; executes row-locked database transaction; prints issue slips. |
| **Issue History** (`#/issues`) | `GET /api/issues/history`<br>`GET /api/issues/:id`<br>`PUT /api/issues/:id` | `bloodissue`, `bloodrequest`, `bloodinventory`, `patient`, `hospital`, `staff` | Audit log of fulfilled issuances; reprint issue slips; update date/staff. |
| **Blood Banks** (`#/bloodbanks`) | `GET /api/bloodbanks`<br>`POST /api/bloodbanks`<br>`PUT /api/bloodbanks/:id`<br>`DELETE /api/bloodbanks/:id`<br>`GET /api/bloodbanks/:id/inventory`<br>`GET /api/bloodbanks/:id/staff` | `bloodbank`, `bloodinventory`, `staff` | Blood bank CRUD; inspects bank-held stock and stationed personnel. |
| **Hospitals** (`#/hospitals`) | `GET /api/hospitals`<br>`POST /api/hospitals`<br>`PUT /api/hospitals/:id`<br>`DELETE /api/hospitals/:id`<br>`GET /api/hospitals/:id/requests` | `hospital`, `bloodrequest` | Hospital CRUD; reviews hospital request backlog. |
| **Patients** (`#/patients`) | `GET /api/patients`<br>`POST /api/patients`<br>`PUT /api/patients/:id`<br>`DELETE /api/patients/:id` | `patient`, `bloodrequest` | Patient directory; non-unique contact numbers allowed. |
| **Staff** (`#/staff`) | `GET /api/staff`<br>`POST /api/staff`<br>`PUT /api/staff/:id`<br>`DELETE /api/staff/:id`<br>`GET /api/staff/:id/donations` | `staff`, `bloodbank`, `donation` | Staff directory; tracks donations collected per staff member. |
| **Emergency Search** (`#/emergency`) | `GET /api/inventory`<br>`GET /api/donors`<br>`GET /api/bloodbanks` | `bloodinventory`, `bloodbank`, `donor` | Live cross-bank emergency triage; direct tel/mailto links. |
| **Settings** (`#/settings`) | `GET /api/health`<br>`GET /` | None (Client storage) | Configures base URL; tests health and latency; customizes thresholds and theme. |
